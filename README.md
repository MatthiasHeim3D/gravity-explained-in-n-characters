# Buoyancy Explainer Doodle

An experiment. Tap the water and something falls in — a rock that sinks, a fish that hovers, a duck that floats — while an explanation of buoyancy flows around it, rewritten to whatever length still fits.

Language models are unusually good at stretching and squashing an idea. Every drop takes room away from the water, so the same explanation has to arrive in fewer characters. The lake is an excuse to watch that happen.

**[Play it](https://matthiasheim3d.github.io/buoyancy-explainer-doodle/)** — tap to drop, drag anything around, resize the window. Back undoes a drop.
